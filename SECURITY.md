# Reporting a security issue

Please do not report a vulnerability by opening a public issue or include claim documents, personal information, credentials, or private URLs in a report.

If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise contact the repository owner privately through their GitHub profile and request a confidential channel. Share only the minimum reproducible technical details needed; do not attach real customer PDFs or production data.

This prototype has no published supported-version policy or response-time SLA. Do not use it with real customer data until the deployment identity, storage, database, monitoring, and incident-response controls have been independently reviewed.
